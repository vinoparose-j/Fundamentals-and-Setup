# Java Full-Stack Development – Internship Phase 1

## About the Project
This project is developed as part of my Java Full-Stack Development Internship. It focuses on learning full-stack development and building a basic web application using React.js and Spring Boot.

## Technologies Used
- Java
- Spring Boot
- React.js
- HTML
- CSS
- JavaScript
- Maven
- Git & GitHub

## Features
- Interactive Hello World application.
- Frontend development using React.js.
- Backend development using Spring Boot.
- REST API integration.
- Frontend and backend communication.
- Basic application testing.

## Project Structure
- **Backend:** Spring Boot
- **Frontend:** React.js
- **Documentation:** Project details and guidelines.

## How to Run

**Backend:**
```bash
cd backend
mvn spring-boot:run
```

**Frontend:**
```bash
cd frontend
npm install
npm run dev
```
